# Breaks — Browser Extension

A browser extension that reminds you to take regular breaks while you work — the browser companion to the [Breaks macOS menu bar app](https://github.com/Aminebenbelaid/breaks-macos).

## Features

- **Two-stage break system** — micro breaks (e.g. every 20 min, 30 sec) and long breaks (e.g. every 60 min, 5 min)
- **Exercise suggestions** — random stretch/movement suggestions per break type
- **Custom reminders** — your own text messages on the break screen
- **Work hours** — only remind during the hours and days you set
- **Warning banner** — floating notification shortly before a break triggers
- **Postpone** — snooze a break by a few minutes
- **Smart idle detection** — if you've been away from the keyboard, it counts as a natural break instead of interrupting you
- **Daily stats** — breaks taken, postponed, and skipped

## Install

1. Download or clone this repository
2. Open `chrome://extensions` (Chrome, Edge, or Brave) and enable **Developer mode**
3. Click **Load unpacked** and select this folder

## Settings

All intervals, durations, exercises, reminders, and work hours are configurable from the extension popup. Defaults: micro break every 20 minutes (30 seconds), long break every 60 minutes (5 minutes).
